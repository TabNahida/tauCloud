# 桌面式 WebPanel

[English](webpanel.md) · [文档](README.zh-CN.md)

状态：交互与 API 规划，后端验收后再实施。方向是类似飞牛 fnOS 交互方式的浏览器桌面：应用启动器、任务栏、可移动窗口和集中通知。[fnOS 初始化指南](https://help.fnnas.com/articles/v1/start/install-os) 展示了从浏览器访问进入桌面的流程。tauCloud 采用自己的视觉设计与应用结构，暂不选定前端框架。

## 1. 桌面壳

- 桌面或工作区包含应用快捷方式、启动器，以及显示运行中和最小化窗口的任务栏/Dock。
- 窗口管理器支持焦点、层级、移动、缩放、最小化、最大化、还原和关闭。对话框不能超出视口，拖动操作提供键盘替代方式。
- 顶层状态区显示当前用户、服务器连接、服务降级、通知和长任务。
- 每用户独立保存壁纸、主题、快捷方式顺序和窗口布局，与文件系统权限分开；恢复窗口时重新验证资源授权。
- 支持应用或资源深链接和可靠的浏览器历史。多个窗口是后端资源的视图，不能各自维护互相矛盾的权威数据。
- 响应式设计：小屏使用单个全屏活动应用与导航，不把浮动桌面窗口强行塞进手机。

初始窗口管理器保持聚焦，多显示器模拟、远程操作系统桌面与任意终端执行不在本里程碑范围。

## 2. 内置应用

| 应用 | 初始职责 |
| --- | --- |
| 文件管理器 | 私人/团队空间、浏览、上传下载、重命名移动、共享策略与传输进度 |
| 控制面板 | 用户组、网络监听、凭据、访问策略和服务设置 |
| 存储管理器 | 物理磁盘 → 阵列/池 → 卷 → 挂载；健康、容量、RAID 计划、替换重建与扩容 |
| 资源监视器 | CPU/内存/网络/磁盘、逐进程资源、协议健康和历史指标 |
| 应用管理 | 已安装插件、显式权限、生命周期与健康；按需执行仅可信代码策略 |
| 容器管理 | Docker 引擎选择、清单、日志统计和已批准生命周期操作 |
| 更新中心 | 可用版本、已验证包、影响服务、维护计划与回滚/恢复状态 |
| 任务与通知中心 | 持久化任务、进度、取消边界、失败和重连同步 |

普通用户看到获准的文件、空间功能与个人偏好；管理应用需要后端授权。隐藏图标不是权限控制。

## 3. 后端与会话契约

桌面壳与全部内置应用通过版本化公开 API 工作，不直接访问进程、磁盘、数据库或 Docker socket。使用统一认证会话和有界共享事件连接，各应用订阅自己的事件，并提供轮询或重新同步兜底。后端任务独立于窗口与浏览器存活，关闭任务窗口不能隐式取消重建、升级或文件任务。

区分浏览器本地上传与服务端任务：如果没有可续传上传契约，关闭页面可能中断浏览器上传。传输状态中明确这一差异。仅持久化不含秘密的续传元数据，继续前重新验证。

可用动作与提供者术语由能力接口决定。保留原生 RAID/Storage Spaces 名称，不支持的操作说明原因。明确展示不可用或过期遥测和服务降级。API 断开不能把未完成操作推断为成功。

资源更新使用修订号，并发编辑进入冲突处理，不能静默覆盖。会话到期时锁定桌面并请求重新认证，不删除服务端任务。API 与前端版本不匹配时显示受控刷新与重连流程。登出清理敏感状态，避免浏览器用户间泄露。

## 4. 存储与升级流程

存储管理器采用查看 → 选择 → 预览 → 确认 → 跟踪流程。磁盘使用稳定 ID 加型号、容量和位置识别，展示受影响数据与使用者，并对具体后端计划取得确认。拓扑改变使预览失效。重建仍在运行时不能只弹一个“成功”提示。

更新中心区分检查下载与安装，展示组件版本、签名验证、预期断线、兼容性和回滚限制。批准后跟踪持久化升级任务；API 重启时显示正在重连，并通过任务 ID 恢复状态。需要恢复时提供具体下一步，不陷入盲目重试循环。

通知链接到资源或任务，对重复故障去重，重连后仍可查看。后台操作显示阶段、影响资源以及当前是否能安全取消。

## 5. 应用边界与交付

第一方应用视图有局部加载与错误边界，一个视图失败时可单独关闭重开，不重置整个桌面。浏览器级故障仍可能影响标签页，但后端进程独立运行。后续如果允许第三方插件 UI，使用独立沙箱 origin/frame 和狭窄、经过验证的消息桥，不能将任意插件 JavaScript 加载到特权桌面同源环境。

M9 根据窗口管理、无障碍、本地化、API 客户端生成与独立打包需求选择前端框架。后端构建不依赖 Node 或前端工具。交付不可变的版本化资源，并声明 API 兼容范围。

M9 验收覆盖键盘与焦点管理、窗口布局恢复、小屏布局、双用户隔离、过期或降级服务、会话到期、并发编辑、服务端任务期间刷新页面、安全的破坏性操作预览，以及组件升级后的重连。先实现后端契约，本文不启动前端实施。
