# M8：插件与 Docker

新增独立 `taucloud_plugins` 管理进程、插件包生命周期 API，以及可安装的第一方 `taucloud_docker` worker。WebPanel 仍属于 M9；详细接口、权限、资源上限和复现命令见 [M8 接口文档](m8.md)。

目前只允许管理员显式信任的原生代码。安装/升级/回滚必须批准准确的 manifest 摘要和完整权限列表，并确认 `trusted_code:true`；安装后不会自动运行，需要单独启用。尚未验证 OS 沙箱，不能把独立目录、进程和 IPC 密钥当作针对恶意同账户代码的隔离。

插件配置与数据在升级、回滚、重启和卸载时保留。worker 有健康检查、原生进程身份验证、256 MiB RSS 限制、退避和崩溃循环状态。全部管理接口（包括 GET）要求管理员角色及 admin 作用域。普通插件不会获得 Docker 端点配置；Docker 权限同时受包权限和端点批准范围限制。

Docker 只接受批准的 Unix socket、Windows 本地命名管道或双向 TLS。协商 API 版本并校验引擎 OS，提供四类清单、有界统计/日志以及指定的启动、停止、重启、删除操作。没有通用代理、exec/attach/build/pull、特权容器创建或宿主路径绑定。Windows 连接 Linux VM/WSL2 时，返回路径属于引擎文件系统，不自动转换为宿主路径。

测试夹具覆盖协议、故障、权限和生命周期。真实 Docker 引擎与 Windows/WSL 部署证据须单独记录，不能从模拟端点推导兼容性通过。
