# ADR 0009 — 有界 SMB3 安全能力

2026-10-30，M6 后端预览采用。[English](0009-smb3-security.md)

扩展现有 SMB 进程与统一文件权威，分别协商 3.0、3.0.2 和 3.1.1。使用 OpenSSL EVP 的 AES-CMAC、AES-128-CCM/GCM、SHA-512 和 HMAC-SHA256 计数模式密钥派生。继续由 NTLMv2 认证提供会话密钥，不自行实现密码算法。两个方向使用不同密钥；3.1.1 绑定完整预认证链，3.0/3.0.2 校验签名的协商信息。

最高共同方言 3.1.1 为现代默认，仍提供签名 2.1 兼容。加密由客户端选择；要求保密的客户端必须要求加密并限制最低方言。只宣告已实现和验证的能力；GMAC、AES-256、压缩和额外传输留待后续。

执行文件操作前验证完整加密消息及所有复合片段头/签名。信用窗口约束 MessageId，拒绝重放；有界 nonce 集合拒绝接收方向复用；发送方向用随机前缀与递增计数。每方向 65,536 个加密帧后需重连，不自动换钥。禁止连接绑定更多会话/通道。认证或安全协商失败关闭连接，并停止后续复合命令。

缓存、变更通知、durable/persistent handles 和多通道分别评估、暂不授予，明确拒绝 durable reconnect、通知和绑定。文件状态通过共同权威立即可见，进程重启后必须重新认证和打开；已提交的删除意图由文件权威恢复。[M6 指南](../m6.zh-CN.md)和[验证](../evidence/m6/README.md)定义已测范围，完整系统客户端/Samba 发布门槛仍保持开放。
