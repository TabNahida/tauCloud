# ADR 0006：有界 PACE WebDAV 与元数据恢复

状态：已用于 M3 后端预览。[English](0006-webdav.md)

锁定 PACE 的 TLS stream 提供增量读写和正常 TLS 关闭，但 HTTP 便捷服务器会缓冲正文。因此 M3 在 tauCloud 中维护小型 HTTP/1.1 适配器，复用 PACE TLS 与有界阻塞执行器。先解析有界请求头，再获取身份授权、接纳正文；每次文件 RPC 最多传输 64 KiB，每响应关闭连接。这样不依赖新的上游 API，也不修改已锁定 PACE 源码；相应解析器及测试由本项目负责。HTTP/2 与 keep-alive 暂不实现。

DAV 属性、持久变更日志及有期限的独占/共享锁属于存储域文件权威，不属于协议工作进程。API 与 DAV 共用锁/配额检查，协议重启不会丢锁。固定原生路径与稳定对象 ID 仍是判断依据。COPY 有字节和树大小限制，超过边界在发布前拒绝；无法确定完成状态的原生操作保留日志待恢复，不静默重复破坏性操作。

流取消时，可用签名真实但过期的授权关闭该用户句柄、取消其未发布 DAV 上传，该路径不能普通读写。持久进度期限和重启清理回收废弃的临时上传；核心 API 的可恢复上传独立处理。

名称由 ASCII 子集扩展为严格 UTF-8 NFC，并使用 utf8proc 检测 Unicode case-fold 冲突。XML 使用 pugixml，额外限制字节、深度、节点、命名空间与字符，禁止 DTD/实体处理。合规声明以独立 litmus 和流式、故障、跨写入端、TLS 测试为依据；桌面客户端兼容性需实际客户端结果。

离线元数据快照要求所有进程角色的独占所有权。恢复发布新状态、生成新密码学身份、撤销会话并清除锁。密码校验值仍属于机密元数据。文件数据和原生 ID 不复制、不映射；当前仅支持原卷恢复。加密、可移植的数据备份产品留待后续。
