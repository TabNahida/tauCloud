# M0 可行性实现

[English](m0.md) · [任务清单](../TODO.md) · [路线图](roadmap.zh-CN.md)

M0 已具备可执行实验、依赖/工具链固定版本、资源预算及双语决策记录。**M0 已按用户在 2026-10-29 指定的功能标准验收：**替代端口互操作已证明实验功能，445 占用仅保留为部署限制。这些实验不是可运行的 NAS，也不代表已支持 SMB/WebDAV 服务。

## 从干净检出运行

安装[版本清单](../toolchains.lock.json)中的参考工具：Python、Git、xmake 和所选 C++ 编译器。更新夹具需要 OpenSSL 3 CLI，Windows 运行器也识别 Git for Windows 自带的 OpenSSL。不需要 Node/前端工具或特权磁盘操作。

```sh
python3 scripts/fetch_pace.py
python3 scripts/run_m0.py --compiler gcc
python3 scripts/run_m0.py --compiler clang --sanitizers
```

离线可执行 `python3 scripts/fetch_pace.py --git-source /path/to/PACE`，只导出锁定提交，不使用其工作区。构建会重新校验导出源码。`--m0=n` 排除实验，`--sanitizers=y` 启用 Linux ASan/UBSan。同一检出中不要并发运行不同 xmake 配置。

Linux 独立 SMB 互操作：

```sh
python3 -m venv .deps/smb-venv
.deps/smb-venv/bin/python -m pip install -r experiments/m0/interop-requirements.txt
python3 scripts/run_m0.py --compiler gcc --smb-python .deps/smb-venv/bin/python
```

第二个独立客户端可通过 `experiments/m0/smbprotocol-requirements.txt` 安装到另一个环境，并以 `--smb-client smbprotocol` 选择。依赖文件固定传递版本，但不是全部带哈希的离线包镜像。

Windows 检出先执行 `python scripts/fetch_pace.py` 获取 PACE，再从 PowerShell 运行：

```powershell
./scripts/windows_m0.ps1 -WithSmb
```

Windows 包装脚本仅把实验源码和已校验的 PACE 导出复制到新建临时目录，在其中创建可选客户端环境，运行 MSVC 及 NTFS/命名管道实验，把报告复制回 `build/m0/windows-msvc.json`，最后删除本次临时目录。`-Source` 可指定已有检出，包括 WSL UNC 路径。不带 `-WithSmb` 时运行不依赖独立客户端的子集，报告会明确列出跳过的互操作。脚本不修改 SMB 服务、防火墙、磁盘布局或现有共享。

## 证据与范围

可审查结果位于 [`docs/evidence`](evidence/README.zh-CN.md)。每次运行记录宿主、Python/编译工具、命令、输出、耗时和实验源码摘要。任何实验非零退出都会使运行器失败。历史报告保留原始 `incomplete` 状态；用户于 2026-10-29 明确取消 445 端口门槛的决定覆盖该状态，不改写任何实测结果。

| 实验 | 可证明的内容 | 不能据此声称 |
| --- | --- | --- |
| PACE 获取 | 固定提交内容、网络/离线导出一致、忽略相邻脏文件 | 完全隔离的系统/工具/包供应链 |
| C++ 运行时 | 贯穿回调的任务/字节限制、上下文亲和、拒绝、取消、超时、异常及上下文销毁清理 | 强制取消内核 I/O、生产进程预算执行 |
| C++ 文件系统 | ext4/NTFS 根相对打开、链接/穿越拒绝、当前对象 ID、打开时重命名/删除、flush 和大小写观察 | 断电安全、NFS 持久句柄、完整 Windows 嵌套路径解析 |
| 恢复 | 真正杀进程/重启、独立接管者、域所有者互斥、同级服务连续、范围/期限授权及版本/代次拒绝 | 生产服务 ACL、多路复用 IPC、持久监督者状态 |
| 更新 | Ed25519 信任分离、并排暂存、FULL SQLite 日志、五个直接退出点及受保护回滚 | 可执行安装器、schema 迁移、断电模拟 |
| SMB 向量/互操作 | NTLMv2 注册/密钥向量、自编回环原型与独立客户端的签名打开/篡改测试 | 通用 SMB 服务、原生客户端矩阵、MIC/channel binding 或外网暴露安全 |
| Windows 宿主 | 系统/夹具文件系统版本、445 冲突检测、替代回环监听 | 标准端口共存或远端防火墙/客户端可达性 |

`filesystem.cpp` 只使用原生临时目录中新建的测试目录，因此 Windows 测到的是 NTFS 而非源码所在的 WSL 文件系统。Linux 如需验证不同文件系统，将 `TMPDIR` 指向该文件系统上的可丢弃目录并记录挂载信息。原生文件操作仅针对这些测试文件。RAID 夹具已设计，不会对宿主磁盘执行。
